# 前三天起步课：13.5 小时

每天 270 分钟，包含短休息、实验记录和排错。目标是建立后续各模块共用的训练基础：能把数据、模型、损失、梯度、更新和评估连起来。它属于 [M0/M1](ROADMAP.md)，不等同于完成两整个模块或学完五套材料。

## 开始前的自测

用 15 分钟独立完成，不查答案：

1. `[32,10] @ [10,3]` 的形状是什么？怎样给每个输出加 bias？
2. 对 `L=(wx+b-y)^2` 求 `∂L/∂w`，解释为什么包含 `x`。
3. 解释条件概率 `P(y|x)` 和联合概率 `P(x,y)`。
4. Python 的类如何保存参数，`forward` 做什么？
5. 训练准确率 99%、验证准确率 65%，首先检查什么？

4–5 项能解释：按计划。2–3 项：用首日时间补关键数学，略过扩展阅读。0–1 项：三天只完成 Day 1–2 的基础能力，卷积顺延。无需为了完成目录跳过理解。

Day 2 使用同一固定划分的 6,000 训练样本、6,000 验证样本，各训练 10 epochs。Day 3 LeNet 复用同一数据。缩小训练规模是为理解与排错，不以完整数据的准确率当硬性门槛。首次正式配置的实际耗时和收敛仍待学习时测量。

## 相比最初课表的调整

- 首日移走传统 ML 和交叉验证，放回 M0 后续；保留训练/验证/测试的基本区别。
- 次日只做 Softmax 与 MLP 两个基线。Dropout、L2 和更长的过拟合对照放到 M1，不要求当天四次训练。
- 第三日只要求卷积与 LeNet。残差网络、小样本长训练放到 M1 后续；不提前塞入 Transformer、LLM、RL 或机器人概念课。
- 把独立写代码、解释和错误分析留出明确时间；Day 2 若无法讲清训练循环，Day 3 改为 MLP 巩固，CNN 顺延。

回归参考脚本使用**全批量梯度下降**，并非 SGD；Day 2 再学习 minibatch 与优化器。LeNet 的学习率与前两模型不同，所以三者是学习用基线比较，不能据此声称只改变网络结构就产生了性能差异。真正的单变量对照在 Day 1 学习率实验和后续 M1 完成。

## 每天的学习循环

读一小节 → 写输入/输出和关键公式 → 预测改动结果 → 运行小实验 → 解释结果 → 关闭资料复述。卡住 20 分钟先记问题，回到小输入。科学空间只围绕一个问题选读 15–20 分钟，并替换同主题阅读时间；视频也用于卡点补讲，不叠加整套课程。

## 第四、第五个学习日如何用

先补前三天尚未掌握的部分。若已通过验收，可进入 M0 传统 ML 的第一个专题时段，或 M1 正则化/训练诊断。原 [day04](../lessons/day04.md) 与 [day05](../lessons/day05.md) 保留为专题工作本，尤其序列/注意力应按前置能力拆分，不能将两份工作本跑完视为长期基础课程完成。

## 覆盖层级与延期内容

| 内容 | 前三天达到的层级 | 后续位置 |
|---|---|---|
| 张量、梯度、线性回归 | 手算、改写更新、与解析解核对 | M0 补概率与统计概念 |

| 传统模型、序列/注意力、LLM、RL、具身 | 尚未完成 | 依次按 M0–M4 推进 |

## 如何判定学会

记录读过、跑过、改过、讲得清。前三天交付自己的 10–30 行核心实现、至少一次单变量对照和一份错例分析；能说明 shape、dtype、设备，以及删除关键步骤会造成什么问题。

完成 [阶段检查](../notes/FINAL_CHECK.md) 的第 1–4、6 题，其余标记未学。测试集不用于这三天的调参；完整阶段模型冻结后再评估。每日日志记录实际学习/实例小时，按 [预算页](COMPUTE_BUDGET.md) 校准后续计划。
