# M3：强化学习基础

预计 35–50 小时。表格方法需要 [M0](00-foundations.md) 的概率、期望与基本编程；DQN/PPO 还需要 [M1](01-deep-learning.md) 的训练基础。来源：[Easy-RL](https://github.com/datawhalechina/easy-rl)。**本模块当前为教学设计，RL 环境与实验待建设。**

## 章节映射

| 内容 | Easy-RL | 预算 |
|---|---|---:|
| MDP、return、价值函数、Bellman、表格方法 | 第 1–3 章 | 10–14h |
| 策略梯度、actor-critic、PPO | 第 4–5、9 章 | 8–12h |
| DQN、经验回放、目标网络与改进 | 第 6–7 章 | 8–12h |
| 连续动作、稀疏奖励、模仿学习与比较复盘 | 第 8、10–12 章选读 | 9–12h |

先价值/表格方法，再 DQN，再策略梯度/PPO，最后选读连续动作等主题。用户给的第 1 章关键词与问答用于自测，正文和项目勘误用于核对。AlphaStar、Minecraft、世界模型等扩展不作为本轮完整训练目标。

## 实验设计

1. 手算一个很小的 MDP 的一次 Bellman 更新；在同一任务实现 value iteration 或 Q-learning，与随机策略比较。
2. 在一个轻量环境训练 DQN，保存 episode return，并画平滑曲线同时保留原始数据；不凭单次最高回报判定学会。
3. 在同一个兼容的小环境运行 PPO 基线，解释策略采样、优势估计和更新目标；不从零复现全部算法细节。选择多个固定训练 seed，并把评估 episode 与训练过程分开。
4. 选一次机制对照，例如 DQN 去掉目标网络；明确算力预算，结果不稳定也如实记录。

环境名称与 API 版本在实现时核验，不把旧 Gym 接口直接视为当前可用。确定环境后区分终止与时间截断，以及二者对 bootstrap 的影响。

## 完成门槛

讲清监督学习标签与 RL 奖励/轨迹的区别；推导一个 Bellman 等式；说明 on-policy/off-policy、探索和评估策略；解释回放与目标网络各解决什么问题。交付随机基线、学习曲线、跨 seed 的波动和失败分析。之后再回看 Happy-LLM 第 8 章，区分通用 RL 原理与语言模型后训练的具体实现。
