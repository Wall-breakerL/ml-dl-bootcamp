# M5：综合复盘与小项目

预计 15–25 小时。在 M0–M4 的核心交付完成后进行，尽量复用已有数据和实验，不默认新增长训练。

## 要串起来的共同问题

| 视角 | 监督学习 | 语言模型 | 强化学习 | 具身模仿学习 |
|---|---|---|---|---|
| 输入 | 特征/图片 | token 上下文 | 状态/观测 | 图像、机器人状态、可选指令 |
| 输出 | 预测/类别 | 下一 token 分布 | 动作或价值 | 单步或一段动作 |
| 学习信号 | 标签与损失 | token 标签；后训练另定目标 | 奖励和轨迹 | 专家动作 |
| 数据来源 | 固定数据集 | 文本/指令数据 | 策略与环境交互，可复用回放 | 专家演示 |
| 评估重点 | 未见数据泛化 | 固定任务/问题集表现 | 独立评估回报与波动 | 闭环任务成功与失败条件 |

这是入门对照，不覆盖每个领域的全部方法。共同的优化工具不意味着数据假设、目标函数或评估方式完全相同。

## 任务与时间

- 4–6h：回看日志，选择三处“跑过但讲不清”的问题，补推导和小实验。
- 8–13h：完成一个个人小项目，从现成任务里选一个扩展点，如模型诊断、固定评估集或策略失败分析；一次只改变一个关键因素。
- 3–6h：整理一页说明、核心代码入口、可复现命令、图表和边界；关闭资料口述 15 分钟。

## 最终检查

1. 为什么模型训练成功不等于对新分布有效？给出一个自己实验的例子。
2. 对 MSE、交叉熵、Bellman 误差和策略目标，分别说明输入、优化变量和数据来源。
3. 解释一个 attention、一个 RL update 和一个机器人动作接口，不依靠术语堆叠。
4. 如果给你新任务，怎样选基线、划分数据、确定指标和算力上限？
5. 列出最不熟的两个主题，给出具体的第二轮学习任务。

交付必须引用自己的 `runs/` 记录；无结果的部分写“待验证”。将个人完成状态更新到 [进度页](../notes/PROGRESS.md)，不要按仓库文件数量勾选完成。
