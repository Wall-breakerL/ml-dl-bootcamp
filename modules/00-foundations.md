# M0：共同基础与传统机器学习

预计 20–30 小时，包含前三天中属于张量、梯度、回归和评估的部分。前置是 Python 函数/类与基础数学；先做 [自测](../docs/CURRICULUM.md#开始前的自测)。

## 阅读与顺序

| 内容 | 来源 | 预算 |
|---|---|---:|
| 张量、矩阵、导数、条件概率与期望 | D2L 第 2 章；按问题补，非整章数学证明 | 5–7h |
| 回归、损失、梯度、数据划分、PyTorch 基本接口 | D2L 3.1–3.3、5 章；科学空间 4277 的梯度段 | 5–7h |
| 传统监督模型与假设 | sklearn 官方入门及模型文档；逻辑回归、kNN、朴素贝叶斯、SVM、树与集成 | 6–10h |
| 泛化评估、交叉验证、PCA/K-means | sklearn Common Pitfalls、CV、降维/聚类文档 | 4–6h |

阅读入口和版本见 [资料页](../docs/RESOURCES.md)。吴恩达这套仓库是深度学习课程笔记，不拿它替代这里的传统 ML 部分。

## 核心问题

为什么负梯度是一个局部下降方向？损失与评价指标有什么不同？怎样把训练数据的信息限制在拟合过程中？线性模型、树和近邻各自表达什么假设？聚类为何不等于预测已知标签？

## 实验与现有入口

1. [Day 1](../lessons/day01.md)：手推 MSE 梯度，比较全批量梯度下降和最小二乘；改变一次学习率。
2. [传统 ML 专题](../lessons/day04.md)：先比较 dummy、逻辑回归和一个树模型，理解后再扩到全部参考模型；用同一 CV 和指标，预处理放在 Pipeline 内。
3. 同一小数据集做 PCA/K-means，说明可视化和聚类不能证明分类性能。

`labs.linear`、`labs.classical` 已有参考实现与准备阶段检查。学习者的完整比较和作答仍待完成；详细记录见 [VERIFICATION](../docs/VERIFICATION.md)。

## 完成门槛

独立写出一次参数更新；讲清训练/验证/测试和三种划分场景；给出一张含基线、指标、数据划分和局限的比较表。能解释 Pipeline 中预处理如何随每一折重新拟合。通过后进入 [M1](01-deep-learning.md)；表格 RL 也可以从这里进入 [M3](03-reinforcement-learning.md)。
