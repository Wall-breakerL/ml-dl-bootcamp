# 服务器时间与费用预算

按用户提供的 **2.28 元/小时**计算。学习时间、GPU 实际计算时间、租赁实例计费时间是三件事。以下估计的是按需开机时的实例占用，不是测得的训练耗时；GPU 型号、数据量、下载速度和排错都会影响结果。

## 完成第一轮基础路线

| 用途 | 预计实例小时 | 费用 |
|---|---:|---:|
| M0/M1：传统 ML 与 D2L 小实验 | 10–15h | 22.80–34.20 元 |
| M2：小语言模型与轻量微调 | 15–30h | 34.20–68.40 元 |
| M3：小型深度 RL 实验 | 5–15h | 11.40–34.20 元 |
| M4：一个仿真任务的数据、训练与评估 | 15–30h | 34.20–68.40 元 |
| 独立预留：环境准备、下载与额外排错 | 5–10h | 11.40–22.80 元 |
| **合计** | **50–100h** | **114–228 元** |

先准备约 **250 元**服务器预算。模块行已包含实验中的正常等待和结果检查，最后一行只算额外准备/排错，避免重复计费估算。M5 尽量复用已有实验；如果新增训练，另记实际占用。

范围：小数据、单卡、代表性实验。具身环境构建和训练是主要不确定项；Happy-LLM 多卡训练建议配置、完整预训练、全部 RL 算法与多任务机器人训练不在该上限承诺之内。Happy-LLM 第 8 章的远程训练服务或其他 LLM API、独立存储费用不在 2.28 元/小时中。

## 前三天

- Day 1 以本地 CPU 的张量、手推和线性回归为主；本地环境是否可运行尚待确认。
- Day 2 集中运行 Softmax、MLP 两个 6,000 训练样本的小实验。
- Day 3 集中运行同一划分的 LeNet，收集错例与检查权重加载。

阅读、推导、写笔记尽量在本地；按服务器环境和数据已经准备好估计，前三天可先给 **2–5 小时实例占用、约 4.56–11.40 元**。这是上述 M0/M1 预算的一部分，不额外相加，也不是三个训练命令实测的耗时。

如果整个 13.5 小时学习过程都用远程 Jupyter 并保持开机，费用就是 **30.78 元**。实例连续开 3 个自然日是 72 小时、**164.16 元**，与每天实际学习几小时无关。

## 如何控制支出

先在本地读课、写代码与准备命令，再集中开机运行；训练结束后保存日志、曲线和必要权重，再在平台检查实例状态。关闭 SSH 或 Jupyter 不等同于停止租赁计费。实际计费粒度、停机与磁盘规则以账户平台显示为准。

每次在学习日志写明开机/停止时间和实际费用，前两次实验后用实际占用修订预算。训练前明确样本数、最大步数、模型规模与失败停止条件。后续 LLM、RL、仿真采用各自环境，不直接覆盖已验证的课程环境。
